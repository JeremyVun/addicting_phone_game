# Roadmap

## Before launch (owner)
Everything in `docs/store/checklist.md`: Play Console and AdMob accounts,
the real ad ids, the five products, the hosted privacy policy, the
upload key backup, the listing and screenshots, an internal test track.

## v1.1
- Play Games leaderboards for the daily (needs the Play Console app id).
- Monochrome-safe notification icon check on real devices; exact-time
  reminder opt-in if inexact delivery proves too late.
- Server receipt validation for coin packs if refund abuse shows up.
- Analytics dashboards on the shared service: D1/D7, ads per DAU, ARPDAU.
- Tune the director from live `game_ended` placement buckets.

## Later
- iOS build (the app is Flutter; ads and billing plugins support it).
- Seasonal themes as paid packs; a second board size as a mode.
